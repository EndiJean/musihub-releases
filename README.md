# musihub-releases

Repositório só para hospedar as releases do MusiHub (o `.apk` do app).

O app consulta `/releases/latest` ao abrir para checar atualização. Se houver uma versão mais nova, avisa o usuário com opção de baixar, mostrando o texto da release como novidades.

Cada release usa a tag `v<versão>` (ex: `v1.1.0`) com o `.apk` anexado.
